# ekakuman.github.io

Bible studies (English + Telugu). Each study lives in its own folder and is listed on the home page (`index.html`):

- `divineblueprint/` · `in-him/` · `thekingdomofgod/` · `kingdom-in-jesus-words/` · `genesis-jubilees-enoch/` · `ascending-and-descending/` · `babel-to-ai/`
- `fullness-of-time/` · `shadow-and-substance/` · `kings-prophets-priests/` · `genealogies-to-christ/` · `life-of-isaac/` · `firstborn/` · `road-to-emmaus/`
- `church-in-scripture/` · `churchtraditions/` · `family-yeilding/` · `things-above/` · `agape-love/` · `parenting-in-genesis/`
- `angelsinscriptures/` · `camp-of-angels/` · `body-soul-spirit/`
- `character-studies/`
- `cross-references/` (chart data in `cross-references/data.json`)
- `places/` (journeys and places; Scripture layer vs human-knowledge layer; data in `places/places.json`, `places/basemap.json`, `places/verses/`)
- `prayers-promises/`

To add a study: create a new folder with an `index.html`, then add a card for it on the home page.

`telehealth/` holds the page that used to be the site home.
