# ekakuman.github.io

Bible studies (English + Telugu). Each study lives in its own folder:

- `in-him/` — In Him
- `church-in-scripture/` — The Church According to Scripture

To add a study: create a new folder with an `index.html`, then add a card for it on the home page (`index.html`).

`telehealth/` holds the page that used to be the site home.
